How to read these results

  • HHS_Care = number of children currently in HHS care (care load).
  • Discharged_From_HHS = daily successful sponsor placements (placement / discharge demand).
  • LinearFeatures uses lag and rolling features (strong for short-horizon / one-step style accuracy).
  • ARIMA / ExpSmoothing are pure time-series models useful for multi-day ahead views without external features.
  • Net Pressure is the operational early-warning signal for capacity stress.
